# 电商图片制作 SOP

版本：2026-11-06 v7，在 `IMAGE-REVISION-2026-10-28-v1`、单图双重审阅及商品保真控制基础上增加单图任务卡、跨轮止损与防退化执行关口。范围：本项目新批制作、整套优化、局部返修。由现有 ecommerce-image-workflow Skill调用，不自动授权作图、外发或付费。

## 1. 启动与最小输入

先读[项目偏好与当前状态](项目偏好与当前状态.md)、根AGENTS和当前要求。确认唯一制作Owner及当前版本，不用历史“当前”段落覆盖最新反馈。

信息记入已有制作清单，不另建多份台账：

| 输入 | 最低内容 | 缺失处理 |
| --- | --- | --- |
| 商品身份 | 各SKU来源、实际需要的正背侧斜角度 | 先做已有角度；新角度不成立再定向补拍 |
| 功能 | 按钮作用、档位名称、实拍对应编号 | 只停依赖未知项的标注，不猜 |
| 外观 | 头部、厚边、颈部、柄部、按钮、孔位、颜色 | 在批量复制前解决影响商品识别的问题 |
| 视觉 | 相关参考、已认可样稿、禁用表达 | 有有效认可直接复用，不重复设计审批 |
| 输出 | 单图／长图用途、SKU、格式与必要尺寸 | 用已有合适规格，不反复补问无关平台 |

本款95普通、96喷雾、97混合；对应不泛化到其他商品。实拍提供商品依据，不要求沿用拍摄房间。量尺照不自动提供精密校准参数；视频辅助理解曲率，不自动等于3D扫描。按需补少量缺失角度，不默认要求60张扫描照片。

## 2. 参考与内容计划

每批完整实际看一次指定参考并保留范围与观察；续接、局部失败、交给既有Owner时复用有效回执。单张只补读相关参考和本SKU实拍。

每图记 `ID / 视觉任务 / SKU / 来源 / 对应参考 / 借鉴点 / 有依据文案 / 输出 / 状态`。计划不冒充实际输出，未运行标NOT_RUN。

借鉴点写“完整人物商品首屏”“三档直接比较”“操作大图与细节交替”等具体特征，不能只写“都是花洒”。参考功能、品牌、证件、参数不继承。

完整度按适用任务覆盖判断：重复项有合并去向，不适用有原因。74参考不是固定74成品，也不能自行限成16张。每张新增图要带来信息增量。

### 2.1 花洒图组顺序与内容分配（2026-11-04）

先按客户给定的本批参考、用途及具体产品调整。下表是从长方形顶喷387—399提炼的**13个可选位置**，适用于需要商品主图、场景与详情的批次；不是规定每批13张，也不是每张都必须出水、有人物或采用黑金。方图/竖图同一内容仅作为不同投放规格时标明“版式变体”，不算新增卖点。实际数量由适用任务、参考覆盖和用户要求决定。

| 顺序 | 任务与画面 | 制作前确认 |
| --- | --- | --- |
| 01 | 主视觉：商品大主体，主要形状、颜色和一个核心卖点 | 本SKU整体外观；对应参考的构图、占比和字级 |
| 02 | 核心出水/使用效果：安装视角与对应水型 | 真实出水位置、可用实拍/视频；无实拍则不把生成效果当实测 |
| 03 | 场景与商品关系：浴室使用环境、商品清晰可辨 | 安装连接、场景比例和商品/配件身份；不暗示随货配件 |
| 04 | 第二水型或另一差异化卖点 | 本产品确有区别时才做；没有新信息就与02合并 |
| 05 | 人物使用体验（若需要）：商品、人体和水流同一场景 | 允许使用人物及身份参考，水流与人、商品的空间关系 |
| 06 | 主要操作或功能：如切档、除垢或启停 | 操作方向、按钮、功能及实拍状态须按本款确认；没有则换主题 |
| 07 | 喷面/接口/材质细节 | 本款真实孔纹、侧边、接口和可证实材质；未知不写 |
| 08 | 竖版场景或第二个使用任务 | 如只是05改画幅标为变体；不虚构额外卖点 |
| 09 | 竖版操作或第二功能 | 如只是06改画幅标为变体；没有真实功能依据就省略 |
| 10 | 综合细节：头部、侧厚、控制件、接口等 | 每个小窗对应实际来源；使用不同照片须确认同一SKU与状态 |
| 11 | 规格尺寸：正侧关系与已确认尺寸 | 仅写真正确认的参数，单位、测量范围和透视清楚；尺寸集中写一次 |
| 12 | 背面/安装及可调角度 | 适配和调节功能须有依据；视角、接头与配件关系真实 |
| 13 | 外观收尾或SKU选择：斜角整体、背面颜色对照 | SKU有区分才做，颜色用各自实拍；若信息重复则合并 |

**套图节奏**：前3张优先让人看懂“是什么、主要效果、使用场景”；中段分别展示有依据的功能和外观；后段承接尺寸、安装和SKU。每张确定一个信息主次，不反复写同一尺寸、功能标题或颜色；功能差异、场景和版式按真实素材调整。切换功能时不得沿用其他SKU或旧款红钮/喷嘴的结论。

**本次示例与边界**：顶喷391/394客户对2026-11-04两张厚度候选满意；它们可作人物、水幕和有立体侧壁的视觉线索，不能作为其他产品外形来源或AI返修底图。用户当时还认可过部分场景及外部389两个版本；认可效果不等于实测水量或逐孔锁定，避免把整套标成已通过客户验收。

### 2.2 AI生图前控制与常见缺陷（2026-11-04）

1. **输入和本图任务先定清楚。** 按本款结构卡选择正、侧、背及操作实拍；以本批对应原参考确定构图、镜头、场景、色彩、字效和主体占比。3D仅作可核验的辅助；人物图按任务使用有效身份母版。缺素材先核已有资料，只有实际缺口影响成图时再定向补拍。
2. **生图说明同时包含五件事。** 写明①实拍商品身份与视角；②尺寸比例、侧壁和孔/盲点/按键结构；③参考图具体构图、光线与文字；④已确认的功能及水流/人物关系；⑤不允许臆造的细节和本图历次有效反馈。模板可写：`实拍【路径/角度】决定【SKU/外形/孔控件】；参考【编号】借鉴【构图/光色/字级】；本图展示【主题】；水流/动作依据【来源或未知】；侧厚按【用户确认或未知】；保留【已认可效果】；避免【本图已发生问题】`。此模板是任务说明，**不是像素或几何锁**。
3. **先防造型和孔纹。** 常见问题：3:2画成方形或拉长；实物有厚度却画成薄片；侧壁夸大成厚箱或高光线冒充侧壁；圆角断开；多图花纹比例不一；真孔变盲点、盲点变孔、增加一排孔、叶瓣叠成鱼鳞；按钮/接口被改造。制作时对照同/近角度正侧实拍和确认尺寸，连同上下面板、边框、侧壁与圆角整体检查；看不到或未确认的部分标UNKNOWN，不补画。几何基于估建时如实标明，不能把AI输入参考或模型存在说成输出硬锁。
4. **再防场景与效果失真。** 实拍直接贴到生成场景可能有轮廓、色温、原环境反射和阴影接缝；全3D可能过平或CG感重；整图AI可能改孔、人体、材质和水流。根据素材选择实拍、3D或实拍引导生图，逐张同时看手机缩略的广告感和原尺寸商品细节。镜面看反射环境而非一味加亮；人物查肤质/身体比例/身份一致；水流查真实出水区域、与面板连接、前后遮挡、密度、硬截断或贴片，不用虚构孔位解决水流。没有实拍水流时可按任务展示生成示意，不能称实测性能或逐孔真实。
5. **返修和交付前防回退。** 合并本轮批注及仍有效的反馈，按§4.1回源，逐图重看结构、比例、材质、人物、水流、字体和已认可构图；只修受影响图，其他图保持。实物准确性、视觉效果、文件核验、用户与客户意见分开记录。示例仅验证实际检查过的范围；提示词、打开模型、尺寸元数据、文件哈希和用户/客户风格满意均不能单独证明逐孔或实测通过。

## 3. 先验证商品与代表任务

新商品／新方向按风险验证：广告主图（商品和风格）、功能对照（水型等区别）、操作细节（标题与动作）。并非每次强制另做三张；已有认可素材直接复用。

代表图通过只证明相应范围：风格认可不证明水型通过，白模认可不证明最后商品照片通过。局部返修不另加用户审批门槛。

本款检查头部圆柱厚边、背壳浅弧、头颈连续过渡与握柄曲率，不能画成直柄球拍或突兀鹅颈。其他商品定义自身关键结构。

### 3.1 每款建立最小结构卡

在当前商品事实里写明：①头部同视角纵横比例/总长关系；②头面内凹或外凸及厚边；③侧面头柄角度和连接过渡；④孔的分组、数量、弧序；⑤按钮真实图标与各模式出水位置。未知留未知，不填想象尺寸。新机位没有对应证据时，优先用已有真实机位裁切，不以全图生成补造型。

先用无水的正/侧/斜图对比结构，再用一张核心水型图核功能；已有有效素材只补不足项，不另加审批。拍摄时尽量让完整主体无遮挡、侧面接近平视、量尺贴同平面，避免仅靠手持近拍的透视估比例。3D有助理解，但白模认可不等于生成图几何被锁定。

### 3.2 商品身份与几何严格控制（通用于各SKU）

每张制作前核对本SKU结构事实、已确认尺寸与功能、对应角度原始实拍、有效模型版本和本图有效反馈；核查并记录准确来源、版本、视角和哪些维度为实测/用户确认、照片估计或UNKNOWN。批次可复用本批已实际核对且未变化的资料，但每图须确认其SKU、角度、用途和变化项；资料变化、换SKU/机位或反馈涉及结构时重新读取受影响原件，不以节省token省略必要核对。缺关键原件只停止受影响内容，不猜造、不跨SKU借事实。

在单图任务记录明确商品主体采用：对应实拍像素、指定版本3D直接渲染、或AI重绘。仅引用照片、模型截图或提示词“保持尺寸”不构成几何锁定；记录模型/实拍实际进入主体的来源和处理方法。应准确展示结构的图优先用对应实拍或经本SKU原照校核的同一3D主体，保留主体与场景分层；AI重绘主体仅可作为标明风险的风格候选，未核实前不得作为准确商品或功能展示。不存在可控主体或必要证据时标NEEDS_FIX/UNKNOWN，不能以模型存在或提示词代替验收。

同组图片固定实际使用的商品主体来源、模型版本与关键结构；机位、缩放和透视可变，不能用画面像素直接当毫米。若确有模型内部变化或新主体替换，记录原因与受影响图并重新对照，不擅改比例、纹样、控件或数量。功能动作、真实孔与装饰点、尺寸、附件、SKU颜色分开核实；未知不补画、不写成确定事实。

交图前对照真实同/邻近角度实拍及尺寸依据，检查主体整体比例、关键外形、厚度、孔纹/控件位置和功能状态；模型渲染另核同一模型版本及可确认的外包络，估建局部不得说成实测。按实际可见范围记录检查和差异；用户或客户认可风格不等于结构、孔数或功能验收。关键项目缺证据、明显不一致或生成重画无法核实时禁止称准确成图；先在授权范围内修复，受限则报告未通过、原因和下一步。技术比对、视觉审阅和用户/客户接受分别记录。

### 3.3 单图任务卡与实际控制（2026-11-06）

在已有制作记录为每张受影响图维护一份简短任务卡，记录 `图片ID/当前版本/SKU与颜色 → 原始实拍及视角、尺寸和适用3D版本（含UNKNOWN）→ 本轮反馈 → 已认可且须保留的构图、风格和已修细节 → 本次实际处理的对象/层 → 候选路径 → 核对结果`。一图多轮更新同一任务卡；复用已真实核对且未变化的批次资料，只补看受本轮影响的原件，不为每图复制全库或新增重复台账。

制作前先明确可控对象：①使用对应角度实拍像素；②使用经该SKU原照核查的指定3D模型直接渲染；③AI重绘，仅为待核候选；④原生文字、可追溯图层或独立水层的确定性修改。记录真实输入与成图主体来源；把实拍、尺寸或3D截图作为AI参考，不等于锁定像素或几何。模型未经该SKU/角度核查不能当准确底座，关键角度或功能证据缺失只停受影响内容，不猜补或跨SKU借事实。

先确认本图需要改变的部分和须保留的主体/画面；优先利用有效原始素材、可编辑源、已核模型和独立图层处理，再按§4.1回源生成需AI重建的像素。没有可用图层时，不得声称整图AI重生成能够保证未改部分不变；先做受影响的代表图并检查，不能只为修一个接口、按键或水流而忽略构图、轮廓与其他部位变化。用户对具体图和操作明确同意的例外按其实际范围执行，不扩展到其他图片或后续轮次。

## 4. 制作方法与止损

| 修改目标 | 优先方法 | 检查 |
| --- | --- | --- |
| 字体／文案／对齐 | 改现有原生排版 | 商品人物是否保持，文字是否截断 |
| 背景／场景 | 独立背景；需AI生成时回原始素材与相关参考重新生成 | 光向、尺度、接触关系与商品变化 |
| 新角度 | 对应实拍，3D辅助理解 | 实物多角度比对，不能生成图互证 |
| 水流／功能 | 已确认档位实拍优先，有可靠素材再分层合成 | 起点、孔位、方向、连续性与模式差异，不加水制造区别 |
| 商品／人物生成图返修 | 回原始实拍、有效身份母版与相关原参考重生成 | 结构、比例、材质/皮肤、手指及清晰度；不叠改旧生成成品 |
| JPG导出 | 同一选定候选一次导出 | 不为PNG/JPG分别生成，原生文件留内部 |

按实际能力记录：自然语言“保持不变”和参考图不是硬约束。内置路径没有Seed／采样器／ControlNet参数时，不称已配置；高价模型或更多Skills不能替代素材与审图。

同缺陷两次有依据修正无改善，停止同路线重抽；AI调用每次均须回源，阈值不允许同一生成成品连修两次。按“回源重生成→实拍整件源层→局部证据对位/独立水层→无可靠结果时退出当前交付并保留历史文件”选择更可控方法，不无限加提示词或靠模型升档。判断输入不足、工具控制不足、合成方法不适合或审查错误。只停受影响部分，其余独立工作继续。阈值是止损规则，不是已验证合格率或工时承诺。

### 4.1 生成图返修：回源重生成

1. 先分清修改对象。原生文字、排版、矢量、可追溯图层、代码及3D源可确定性修改后再导出/渲染；需要AI重建的像素不能沿用上一轮生成成品做连续编辑。
2. 重新读取本图相关原始实拍/素材、有效身份母版与原参考，将历次仍有效的反馈、已认可风格和本轮修改点合并为一次生成输入。旧候选只供审阅对照，不再作为待编辑图传入；原件缺失则记录该图缺口，不用旧成品冒充。
3. 只重新生成受影响图片或像素层，未改图和可编辑源复用；新候选另存，原件与旧版保留。不能因改单张而换整套方向，也不能用“局部返修”绕过回源要求。
4. 记录真实输入、反馈合并与输出版本。重新生成后复查整张新图的轮廓、比例、孔/按钮、材质/皮肤纹理及清晰度，并对照原素材和上一版检查是否退化；不能只看批注处。

### 4.2 跨轮止损与方法切换（2026-11-06）

按 `图片ID + 同一可见缺陷 + 方法路线` 在该图已有记录累计尝试，跨对话轮次、压缩和重开不清零；记录每次输入依据、方法、候选和实际结果。若两次有依据修正后该缺陷仍无改善，停止受影响图的同路线重抽；仅改提示词、颜色、构图、模型档位或多读一次文件不算已改变控制方法。不同图片或不同缺陷不机械合并计数；若证据不足以判断是否改善，先标UNKNOWN并定位，不伪造失败或通过。

按实际问题选有新依据的方案：核实拍/视角是否足够；使用同角度完整实拍或经校核的3D直接渲染；从可追溯原生源做局部和独立水层；必要时缩小任务、选择已有真实机位或定向补拍。镜面融合、水流和文字仍要达到广告质量，不把粗糙拼贴或灰模当成通过。没有合适源或方法时保留候选和缺口，报告NEEDS_FIX，其他独立工作可继续。AI返修与用户明确例外分别按§4.1和当次具体授权处理，不把一次例外泛化。

上下文压缩、规则数量或使用的模型可能影响执行，但须有本任务记录和对照才能判断；不得把换会话、升档或重读SOP当作保真修复。必要对照应固定素材、目标、视角和验收标准，记录实际模型/工具与结果，不凭自述或套餐用量推断生成能力。

## 5. 单图制作与审阅

制作前实际看相关原参考、商品来源和批注，通过工具支持方式引用并注明用途。清单区分实拍像素、实拍引导生成图和3D渲染。

制作后使用[检查清单](../.agents/skills/ecommerce-image-workflow/references/checklist.md)：缩略看识别与层级，原尺寸看商品、水流、人物、字边；有问题再放大对应区域。

一图一个主要主题。下方已有色名／档名，上方不再重复；不用空泛副标题填空。必要信息清楚呈现，不加细小底注。完整头缘留栏内安全距离，等比展示；下柄自然出画，不能拉伸塞栏。

关键商品／功能／人像缺陷未解时，不因文字正确、文件齐全而判全通过。

### 单图任务卡与双重审阅（2026-10-30）

在已有单图制作记录中简记：图片ID及主题、用户认可的构图/风格参考、原始实拍及角度、不可改变的商品与画面要素、本轮问题、拟改源层和输出。有效反馈合并继承；“继续”不自行换主题或丢弃已认可方向。旧生成候选仅作风格对照，AI重建仍按§4.1回源；可追溯原生图层可确定性修改。

先核实拍是否支持目标角度：整件优先以同角度完整实拍控制喷面、外缘、头颈、手柄、按键与接口；3D仅辅助理解，不能以白模通过替代最终实物对照。若只用实拍喷面与生成机身拼接，必须同时核整个轮廓、比例、接缝和控件，不以中心像素一致证明全商品正确。素材不支持所需角度或反光处理时，明确局限，选择可行构图或定向补拍，不猜造结构。

先确定真实商品的大小、位置与角度，再制作与之匹配的场景、光向、接触阴影、反光和独立文字；保留已认可的广告层级和视觉节奏，不把实拍抠图加模糊阴影当完成。保留必要可编辑源和来源。

交用户前由制作Owner同时检查：①对照原始正侧实拍的喷孔、红钮、银键、外缘、头柄连接与接口；②对照认可参考的主体占比、构图、光色、字体、层次、手机缩略可读性及贴图/接缝。记录实际查看范围与未核项，不能用自动像素检查替代整体视觉审查。明显缺陷先在授权内修复并复看整图；无法解决则报告具体阻断和可行下一步，不称通过。用户与客户接受单列。

先完成受影响的代表图及其喷面、头柄原照对照；代表图通过只代表该图与已核范围，再按现有授权续作，不自动扩套。相同缺陷按§4止损，不为凑候选反复换背景或主题。

### 5.1 一分钟局部缺陷检查

实拍层进入排版前先查表面清洁度：面板孔间的深浅水渍、红钮/按键指纹、金属面污斑和灰尘。完成排版后原尺寸复看，可疑处放大至200%；去污只改确切污渍区域，不擦掉孔口阴影、磨砂颗粒和真实反射。清洁后的源按版本复用，不能把带污渍原照反复当成合格商品层；本次局部返修仅同步实际受影响的输出，不顺带重做其他图。

改动后先看受影响对象与四周：孔/按钮图标是否被简化，指缝/接口是否残留原背景，贴图是否出现横缝/色温突变，银色反射是否过度染金或磨平。对光滑金属先对照原照，不能把真实窗影当裂纹；二维孔层投影不能纠正面板凹凸。整件商品只作等比变换，不拉长白孔或单独压短柄。

第三方反馈先分“已见明确错误、需实拍验证、偏好建议”。没有原图的审查不能直接判真实弧度；只修本地证实或用户明确指定项。功能名修改同步操作图、模式对比、长图与总览，先盘点后一次改完。

### 5.2 多约束同时验收与防退化（2026-11-03）

1. 在本图已有任务卡中，把有效要求合并成一份检查项：商品真实结构及已确认尺寸、真实或明确标为未知的功能、水流或场景效果、已认可的风格排版、本轮批注和历次已修问题。尺寸、3D和实拍须按§3.2核实际来源与适用角度；有模型或读取文件不等于几何已经锁定。记录本次实际进入成图的主体来源，缺依据填UNKNOWN，不因风格相似认定孔位准确。
2. 每个新候选实际并置查看对应原始实拍、适用的3D/尺寸依据、用户认可的效果参考和最终整图。分别在手机缩略、原尺寸及有风险的局部放大检查商品、构图、材质、光影、排版；对照任务卡逐项写通过、未通过或UNKNOWN和可见依据。关键商品或视觉缺陷有一项未通过，就不能把该图称为合格成品；用户认可风格与商品真实性分开记录。
3. 含出水画面必须同时核对：水流是否自然连接到有依据的出水区域、近孔遮挡和透视、密度与亮度是否符合用户参考，以及边缘是否出现悬空、硬直截断、矩形贴片、重复线条或明显接缝。水幕更饱满不能靠虚构密排孔，孔位正确也不能以明显断流或拼贴作为通过；资料无法证明每束水与每个孔的对应时记录未核实，不假称逐孔准确。
4. 每次返修重新检查本轮修改点及所有仍有效的已修/已认可项，不能以一个指标改善掩盖另一项退化。记录“反馈→本次处理→逐项实际结果→遗留问题”；用户指出的明显错误不得再次原样交付。若同一缺陷两次有依据修正仍无改善，按§4停止同路线，分析素材、方法和合成限制，提出有新依据的替代方法；仍无法解决时保留失败候选供诊断，不冒充通过。AI像素重建仍须遵守§4.1回源规则，不能把上一次生成成品重新送入模型。
5. 实际效果优于本次候选的用户参考，可用于分析水流、光影、构图等视觉优点；用户认可外观不自动等于商品结构、功能或尺寸核实。不能通过单纯增加提示词、读取次数、模型档位或文件检查替代最终图面审查。
6. 每张候选交用户前，在已有任务卡对照原始实拍/适用模型、上一版和新图，逐项记 `本轮修改/主体结构与对应SKU颜色/功能水流/已认可版式与历次已修项/视觉融合 → 通过、未通过或UNKNOWN及依据`。例如尺寸侧视核头柄相对角度；多色图逐SKU核接口颜色；出水核孔口起点、方向和连续性。已知关键缺陷不得只交由用户发现或称修好；用户主动要求查看失败候选时可如实展示问题。单项改善、单张用户认可、文件打包通过与整套客户接受分别记录。

## 6. 整套与长详情

先写每章新增信息，再排图序。可用逻辑：完整场景吸引注意 → 商品选择 → 三档对照 → 操作 → 除垢状态 → 外观 → 选购信息，按商品调整。

- 全幅场景、紧凑比较、操作大图、细节与信息交替；避免连续相同角度和标题模板。
- 统一色调／字级不等于同版复制；修保真不能丢广告表达。
- 合并重复按键、背面、头柄章节；状态照片不冒充性能／清洁效果测试。
- 长度比较换算同宽，并识别参考空白及本商品无依据章节；长度不是独立合格指标，变短如实报告。
- 查看长图各段和衔接，检查重复标题、主体截断、密度突变。章节改变后同步组装。
- 并置图先用手机宽度检查，去掉无信息增量的窄侧条和硬分割。无法自然并置时用一张完整场景。单图允许改为竖幅；长图章节按宽等比算高，后续章顺延，不能硬压回旧高度。

“大方向差不多”代表保留已认可风格并收敛处理范围；生成图仍按§4.1回源重生成，原生排版/源层可局部修改。遇重复色名，定向检查重复档名、空泛副标题等同类项；不借检查重做无关图。

## 8. 导出与交付

1. 选定候选导出JPG；内部原生、Mask、PNG保留，客户包只放约定成品。
2. 更新单图后同步长图、HTML、manifest、ZIP，当前指针唯一，旧版保留。
3. 最终JPG读取检查尺寸数量，ZIP CRC及成员哈希与manifest一致。
4. 分开报告制作、内部图面审阅、文件检查、用户／客户接受。未接受仍可给用户本地审阅包；打包通过不等于客户通过。
5. 完成给预览、完整包和必要限制；不只交“已派发”。工具失败报告真实错误，不编造能力限制、完成时间或后台承诺。

### 8.1 获明确授权后的收尾清理

默认保留素材。用户明确确认删除时：先列明本款路径、保留集和原件范围→核最终JPG/ZIP与预览→收拢必要编辑素材/字体/章节映射与可复用脚本，验证不依赖待删目录→固化经验→逐文件核身份/哈希后删除→确认目标缺失、保留文件哈希不变及`df`前后差。已缺失路径单列，不算本次删除。最终可编辑合成层不冒称原始实拍、全分层或可重新棚拍。

旧目录不要为每次返修整套复制。正常制作只存变化源，最终收口一套交付；历史清理依当次授权，不自动删除其他产品、74参考、系统缓存或附件目录。清理后当前入口标注原件已删除，不能继续声称可从本地原片核验。

### 8.2 打包前核对实际交付意图（2026-11-03）

1. 以用户最新要求为准，在已有交付记录写明：要单张还是完整套图、每套数量、哪些保留、哪张由哪个指定版本替换、格式和命名。结合相邻对话与现有套图核实；指代存在实质歧义时先核可用上下文，仍不能判定才询问，不能自行把“整套”缩成仅打包新增两张。
2. 多方案应逐套列清单，逐项核数量、序号和替换关系；不受影响图片核字节一致，用户指定原图直接交付时核包内与指定原件一致，尊重用户明确要求保留的原格式；JPG默认规则不覆盖明确的原文件打包要求。使用新包名或新目录，保留现有成果。
3. 重新打开ZIP核成员、完整性及与实际输入文件的对应关系；检查通过只代表文件与清单一致，不代表图面质量或客户接受。报告套数、每套数量、各版本差异、原图格式和仍未核实事项。
