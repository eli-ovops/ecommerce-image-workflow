# 花洒电商图片全流程复盘

日期：2026-10-25。依据本聊天用户／客户反馈、实拍与建模过程、制作记录及[最新精修审阅](../production/2026-10-25_广告节奏优化_细节精修/visual-review.json)。本次仅固化文档。

## 核心结论

商品形状、功能真实性和广告风格没有分别验证就批量扩展，基础错误被复制。随后整图重绘与碎片修补相互牵连，保真修正又损失了用户喜欢的广告感。素材逐步补足，但主要可控问题在制作和审查方法，不能把低合格率归因于照片、模型档位或Skill数量。

用户报告早期耗时15–20小时；缺少逐图完整计时和客户通过样本，不能计算精确成本、合格率或新流程节省比例。

## 失败与修正

| 失败 | 根因或实际限制 | 固化措施 |
| --- | --- | --- |
| 头部、颈部、柄部漂移 | 生成工具重新解释外观；单图与描述缺乏跨角度约束 | 关键角度先比实物，未过不扩散；3D仅用于已验证范围 |
| 模型反复改仍不像实物 | 二维轮廓加预设截面不是三维真值，局部认可不是整体通过 | 按侧照、视频和具体纠正改局部，停止无新依据调参，不追不必要工业精度 |
| 半边出水、普通与混合不清 | 密集孔／水束缺画；档位映射晚确认；重绘改水型 | 功能先绑照片，先审核心对比；不单靠标签／加雾制造区别 |
| 六点喷雾位置错误 | “全孔出水”的通用要求与模式混用 | 分模式检查，六点位置依据圈注实拍 |
| 人物鱼鳞纹、越修越脏 | 多轮重绘的可见质感劣化；具体内部机制不可断言 | 回干净母版和原商品来源，正确候选保留，停止坏图叠修 |
| 修保真后变说明卡 | 技术修正替代广告目标，风格没有单独验收 | 同时验证商品与广告感；整套看构图、光色、字级与节奏 |
| 随手拍房间进入成品 | 混淆商品来源和场景来源 | 商品依据用实拍，环境独立设计，检查光向接触 |
| 螺纹过多 | 完整展示优先于广告构图 | 合理持握／机位／自然出画，不强制每张露接口 |
| 长图先短后重复堆长 | 先拼现有单图，再按像素补章节 | 先定义信息增量，合并重复，比较同宽有效内容 |
| 小字、否定说明、重复标签 | 内部工程说明进入对外画面，审图未剔除 | 正向重点文字，一图标一次，查同类重复 |
| 三色截边或尺度不一 | 只确认文件生成，未查分栏实际边缘 | 等尺度、等比居中、完整头缘安全边距，打开原图查 |
| 文件通过但客户否定 | 机械完整性被当成视觉正确 | 分开图面、功能、文件与客户验收，不伪造算法分数 |
| 多文档仍称旧阶段当前 | 路由和版本指针过时 | 一个当前入口，历史明确标记，新授权和反馈持续有效 |
| 未核工具就说无法处理 | 把未经核实的能力判断当事实 | 报真实错误，查受支持替代，不编造限制／进度／后台承诺 |

## 有效经验及适用范围

1. 直接复用干净人物图降低再次损伤风险，但不等于任意新场景身份自动一致。
2. 商品、背景、文字分层使字与排版快速修正；生成商品层仍可能偏离实物。
3. 原实拍裁切可保留孔位、红针和按压状态；不能证明清洁性能，也不必照搬房间。
4. 各色独立来源、等尺度有利于比较；不能调色替代未拍SKU。
5. 去小字、去重复、精修裁切比整体重抽更有效；最近D01/M04/D02局部改，其他14张字节不变。
6. JPG与ZIP回读保证用户拿到同版文件；不证明几何、水流或客户接受。
7. 单Owner制作加明确边界的独立审阅减少冲突；并行不是越多越快，不能同图多头制作。

## 仍未解决与不能声称的内容

- 当前生成几何与水流靠人工对照和既有候选，没有严格网格硬锁、逐孔算法或客户全套接受。
- 固定Seed根除伪影未经证明，当前内置接口未暴露相应参数，不能照抄技术建议称已启用。
- 没跑过IoU≥0.96、边缘1.5%、肤质频谱或自动水束覆盖率；主观90分不能替代这些检测。
- 镜面摄影测量有困难，本项目采用辅助模型；视频抽帧不能称扫描成功，扫描不是每个商品的必经步骤。
- 代表图风格认可、用户大方向认可、文件核验、客户接受及商业成交必须区分。

## 2026-10-26 方形三键款：本轮增补

本轮已交付最新17张JPG（16独立+1长图）；用户转述客户大方向无明显问题，之后仍逐项指出缺陷。不将这一反馈记成每张几何、肤质、水流均已通过。最新成品入口是 `production/2026-10-26_方形三键花洒_喷枪名称修订/`。以下是实际经过反馈修正的方法，未取得逐分钟统计，不报告虚构节省率。

| 碰壁与代价 | 已验证有效的改法 | 下次提前检查 |
| --- | --- | --- |
| 简称“方形”后多次画成近正方形，面板偏短；局部拉头又拉长喷嘴 | M03、D07改用各色整件实拍层等比旋转缩放；不分别变形头/柄 | 同机位核头面纵横比、头柄比例；名称不是几何证据 |
| 3D/贴孔后仍把浅凹面画成外鼓，俯视柄错误露出 | 补斜侧实拍确认高边与退入面；顶视按真实遮挡而非为了露全商品 | 先看正/侧/斜/顶的凹凸、侧壁、轴线和遮挡，再扩角度；二维投影只解决二维对位 |
| 白孔排列被随机化，数量对但弧序不对；按钮图标变成T形/长直线 | 按清晰实拍逐组对位；M02/M04三枚按钮各自局部投影和亮度匹配 | 将弧序、7心形、6黑嘴2×3和三个图标分开查，不能互相代替 |
| 喷雾重抽造成贴面粉雾、起点错位、与上下模式不同场景 | 采用210整件商品与手层、原坐标同变换、独立水层；先孔位后浓度 | 模式先绑实际喷嘴/键位，六束因透视可交叠；不用全局“全孔出水”覆盖所有模式 |
| 只强化水量遮住了出水位置问题 | 增强仅限独立水层，保留六起点与真实商品；水量是广告表达不是实测证据 | 增强前先验起点和方向，不用气氛遮掩结构 |
| 抠图带入指缝墙面、接头三角残片，贴片出现横缝 | M05修指缝mask，D07重做连续底图与原生字体，不整图重抽 | 对每个手指间隙/接口边/分栏接点放大检查，手机缩略再看整体 |
| 左完整场景+右孤立窄条让N06割裂 | 删除右条，保留统一手持场景；改994×1254竖幅，长图等比1262高 | 有信息增量才并置，不为方图或旧章高拉伸；衔接同步移动 |
| 镜面反射被当成形体问题，或硬磨平后失去金属感 | 核原187/192等证据，局部弱化冷色/肤色与杂乱窗影，保留合理高光 | 先分反射、材质、真实外轮廓；局部修不等于重新棚拍或完全去反射 |
| 仅修一处术语导致其他图与长图称呼不一致 | “顶部喷枪”一次更新D03、D01、M05与L01直接引用 | 文案保留统一事实表、图ID引用表；改字不重画商品 |
| 大量历史目录、ZIP与相同JPG复制增占空间，脚本依赖前版目录 | 收尾只留最后交付及必要编辑资产、章节映射与可独立核包脚本 | 开工保当前指针；返修存变化；清理前独立化、核哈希与链接，按明确授权删除 |

有效的审查顺序是：实物身份与结构 → 功能/喷嘴关系 → 广告场景与字体 → 局部合成边界 → 手机宽度整体节奏 → 长图直接引用 → 文件与包一致。第三方报告没有原图时，只提供可验证线索；文件CRC或主观评分不证明真实商品几何。

用户偏好已稳定：完整、统一、有广告感的场景；大主体、粗斜中文标题、暖白/铜棕/黑金有节奏变化；不喜欢说明书式碎卡、细小底注、重复色名/档名和未包含说明。相同构图只换三种颜色是一个视觉任务，不用作三张有效内容凑数。螺纹自然遮挡/出画，不能为了不露螺纹缩短产品。不同产品不自动复制前款红钮、混合档、接口颜色与尺寸。
