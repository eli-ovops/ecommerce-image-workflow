# 长方形顶喷：孔位与广告图续研

日期：2026-11-02。用户明确确认研究对象为当前长方形顶喷；圆形款研究维持暂停，原有资料和失败版本保留。本次为定向资料研究及既有结果复核，没有新生成图片、安装软件、上传图片或声称客户验收。

## 针对的问题与本地证据

- 用户指出13张候选中的392除垢方图、399斜放竖图孔错误：叶瓣内出现多余黑点，封闭圆点与出水孔混淆，红针也跟随错误孔位。对应两图状态已标重做，旧候选和压缩包保留为历史。
- 实拍372及376为喷面依据，374为侧厚依据，382为拉出时短红针局部。机身300×200×20毫米由用户确认。原始孔位表把可见位置分类为96通孔、132非孔圆点和1个遮挡位置；这是人工照片分类，不是厂家确认总孔数。
- 既有3D源与实拍颜色UV叠加的同灯光候选，叶瓣可辨、没有出现同类叶瓣内新增孔，但存在偏心叠圈、下沿银边发黑及广告感不足；392未获得合格替代，不能将孔数记录或几何检查当作交图通过。详见 [root复核](../production/2026-10-31_顶喷孔位回源可控修复/root-review.json) 与 [同灯光复核](../production/2026-10-31_顶喷孔位回源可控修复/uv-color-candidate/same-light-check/README.md)。
- 这次根因是多个环节叠加：生成模型会重画孔；固定几何和实拍纹理分别绘出孔圈时配准误差造成双边；同一轮同时改变曝光和灯光会干扰材质判断；镜面边缘的环境反射与新场景和接触阴影不一致，会出现贴图感。最后两项是根据当前记录及摄影原理作出的诊断，不是对每个像素的自动测量。

## 资料与具体案例

1. **Earthlite/Living Earth Crafts 场景合成案例**：[Product Image Pro](https://productimagepro.com/case-studies/earthlite/hybrid-environment-compositing) 页面叙述使用原产品照片作为依据，围绕其相机角度设计环境，分别处理产品蒙版、建筑、道具、光影和接触阴影；最终用传统合成及选择性生成结合。该公司对项目成果的描述属于案例方自述，未独立核验其源文件或结果。对本品的启发是先固定可用实拍的角度，再围绕它做广告，不能仅凭背景好看就算融合成功。
2. **Majestine 反光珠宝拍摄案例**：[Photography Firm](https://www.photographyfirm.co.uk/case-study-majestine/) 描述用反光板填充，再用黑旗与卡片制造金属暗反射以定义轮廓。它是摄影公司自己的过程说明，产品并非花洒；对我们的启发是银边需要有可解释的明暗反射带，而非统一涂暖金或单纯提亮。
3. **限定修改范围与图层保护**：Adobe [图层蒙版](https://helpx.adobe.com/photoshop/desktop/create-masks/layer-masks/add-layer-masks.html)、[非破坏性编辑](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/create-layer-compositions/non-destructive-editing-techniques.html)说明可通过原始图层、蒙版与智能对象保存可修改的源；[合成要点](https://helpx.adobe.com/ph_fil/photoshop/how-to/photography-effects.html)强调透视、光向与光质一致。蒙版本身不保证边缘自动准确，也不证明一次缩放、旋转或压缩后的每个像素值仍相同。
4. **生成选区外也要检查**：ComfyUI项目的[公开问题16434](https://github.com/Comfy-Org/ComfyUI/issues/16434)有用户报告生成后非编辑区发生亮度/颜色变化，建议把结果按蒙版叠回原图；这是用户提出的问题与建议，不能当作所有版本的通用基准或已验证修复。对我们而言，最后输出应由明确保留的主体源层合成，不能只靠文字提示“保持孔位”。
5. **3D接触阴影与蒙版**：[Blender渲染通道手册](https://docs.blender.org/manual/en/latest/render/layers/passes.html)介绍Shadow Catcher及Cryptomatte通道，可辅助分离渲染阴影与对象蒙版。它们能提供可编辑素材，不保证与照片中的真实反光、灯光和地面透视自动一致。本轮看到搜索缓存内容，直接打开同页返回402；未实际运行Blender复现。
6. **生成式重打光的边界**：[IC-Light作者仓库](https://github.com/lllyasviel/IC-Light/blob/main/README.md)介绍以图片、文字或背景条件生成不同光照，属于生成式图像处理；作者没有承诺保留本产品逐孔像素。[ECCV论文摘要](https://arxiv.org/abs/2408.09702)指出单图插入同时维持物体细节和一致阴影/反射存在挑战。论文提出的方法未在本项目安装或测试，不能把论文结果当成本项目效果。

## 可尝试的4个方向（研究排序，尚未验证）

### 1. 完整实拍主体 + 同角度广告场景

先从372/376选出主体无遮挡、圆角、面板与银边最完整的一张，整体作为同一来源层，建立可复用的精细主体蒙版。以该实拍的相机角度和光向为起点，设计深色石材、广告式主体占比、灯带和台面；阴影、银边反射与背景分层处理。只在材质边缘和场景层做必要的确定性调色，不用生成模型重绘喷面/红钮。优先用于静态斜放或竖放图，不能从平视素材直接保证极端仰视图真实。

验收：实拍和结果同尺度对照，所有可见孔/封闭圆点和叶瓣内无新增黑点；主体整体比例、圆角、侧厚/红钮与实拍一致；轮廓不夹带原背景；接触点有连续阴影，银边明暗和场景光向协调，手机缩略图仍有广告感。原生层需保留；经缩放/旋转/导出后不宣称逐像素相同。原图本身的摄影光斑仍需检查。

### 2. 实拍喷面作为唯一可见孔圈 + 3D银壳/边缘

如果需要适度调整角度，可在受控3D中使用实拍面板作为唯一可见的喷面外观，背后3D负责厚度、外围轮廓与受光；避免照片孔圈与渲染孔圈在同一可见表面叠加。此路线保留真实孔纹外观，但照片贴到平面/曲面后变换、重采样、视角、纹理光影和3D接缝仍需检查；并不证明它是可用于工程、流体或真实穿孔的实体。不可把这次已失败的“照片孔圈＋模型孔圈重叠”换个名字当作新成果。

验收：先同视角做照片与投射层的孔心、盲点和叶瓣对应图，检查无双圈、无叶瓣内黑点；再看红钮、外壳弧度、接缝、银边反射和接触阴影。大量转角、素材缺失或出现明显贴片感即停，不用夸张变形掩盖。

### 3. 受保护喷面 + 分区域光影修饰

实拍孔纹与中央按钮保持受保护，独立处理银色边缘、背景和接触阴影。必要时可研究局部生成式重打光或Harmony类工具，但仅在明确区域试用并与原始层合成；不能让生成光效穿过孔纹保护区，也不能把模型输出当原始像素。优先保留可编辑蒙版和原图，可审计每一层。真实光向及镜面内容无法从单照完整恢复，存在色温割裂、反射不合理、边缘光晕。

验收：分别打开保护层、光影层和成图，对照孔点与盲点、轮廓/金属高光、背景光向、色温、地面接触和原尺寸清晰度。先做一张代表图，再决定是否复用。所列工具目前未在本SKU复现。

### 4. 原生3D孔纹 + 实测外观/补拍素材

已有3D外观模型可维持孔/非孔分类，但叶瓣材质、光影与真实感仍未通过。后续若需要同一商品多角度且前三法均不足，针对孔圈/花瓣的错位、外壳反射和灯光单独做受控验证。若现有照片不足以支持镜面或拉出状态，可再明确最少补拍：机位固定、主体完整、不同柔光/反射卡的同角度照片；拉出状态须无遮挡，必要时附尺。3D内部结构、针行程和工程精度仍不可凭外观估算。

验收：分别看原照与同角度渲染、几何孔/盲点采样和未标注细节，锁定同一商品网格，再逐项测试材质与灯光；不能只报告几何通过。补拍和设备需要以现有素材实际不足为前提，不要求现在重拍。
