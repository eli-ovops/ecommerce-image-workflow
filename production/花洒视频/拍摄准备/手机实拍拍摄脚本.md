# 花洒广告视频：手机实拍拍摄脚本

日期：2026-10-25。用途：拍摄约30—40秒广告所需原始素材，最终时长随有效素材调整。主推银色，三色陈列为选拍。参考视频只借鉴展示方式，不继承其滤芯、材质或性能宣传。

## 三条参考补充核对后的执行修订

2026-10-25：三条参考均按每0.5秒取样、顺序查看覆盖全时段画面（29.70/30.07/32.00秒）；未连续观看或直接听音轨，不作为完整视听审阅。证据位于 `production/视频参考分析/2026-10-25/细读/R1-01.jpg` 至 `R3-04.jpg` 共12页。参考中的图形、文字、漂浮效果不当实拍结构证据。

- 默认成片竖版9:16。三条参考均为3:4；拍摄用竖屏9:16并把商品/动作置于中央，给后续3:4裁切留余量，不切掉关键水流。
- 布景以一个干净浴室为主，深灰背景水流优先；不要求搭黑棚或整套换风格。黑背景外观仅选拍，保持侧光，别只把曝光压黑。
- 05/06/07每档多录到15秒：先空流5秒，手掌从侧边进入接水3秒，再移开，空流5秒。喷头位置、背景、曝光和供水开度保持一致，便于三档切换和分屏。普通、喷雾、混合分别拍，不能照参考拍单柱激光档。
- 新增11：出水孔近景，手机从侧下方斜看出水面，完整喷头及孔口下方约15—25cm水流入镜；普通、喷雾、混合各8—10秒，不伸手遮挡。用于看清雾束从哪里出来，比只有远处白雾更重要。
- 03补一条斜侧近景：不开水，从面板侧前方对焦孔口，中央红钮按下2秒、松开2秒，重复两次，录12—16秒；机位以真实看清红针高度变化为准，不硬用不具备的微距。
- 04连续切档保留；另拍下方按键的干态特写10秒，按三次，每次间隔2秒。剪辑可插入，但不冒充同镜头连续切档证据。
- 参考1借鉴外观/操作/水流交替；参考2借鉴同机位水型展示、按键特写；参考3借鉴暗背景水流与局部侧光。滤芯拆卸、大小/水压对比、单柱激光水、蜂窝结构图形不拍；接口无确认宣传需求，不拆装凑镜头。
- 推荐约35秒剪辑：水流开场3秒→外观侧面4秒→下方按键3秒→三档各4秒→红钮及红针6秒→三色或银色收尾4秒；按有效素材调整。

## 开拍前统一设置

- 手机竖拍，后置主摄1×，优先4K/30fps，不支持则1080P/30fps。关闭美颜、滤镜；默认不用慢动作。不要数码放大。
- 手机固定在支架或稳固位置；保持同一方向。每条原片动作前后各静止2秒，不提前掐断。
- 商品擦净、镜头擦净。穿纯色衣服，手部整洁，避免反光里出现杂乱房间、手机和人脸。
- 外观段用干净浅色背景，水流段用稍暗、无杂物的浴室墙面。用柔和窗光或侧光，避免手机闪光灯直照银色壳体。灯具放在干燥处，拍水流时不要临时拿接电灯具靠近水。
- 点击商品锁定对焦/曝光（手机支持时）；银色高光看不清细节时稍降曝光。先试录，放大回看是否清楚、有无灯光闪烁。
- 外观镜头尽量让花洒占画面高度约三分之二；顶部留一点空位便于后期放标题。不要切掉喷头边缘和关键按钮。
- 水流镜头保持同一供水条件、相同水龙头开度。手机放在水束侧面，不正对喷口；让水落在排水区域。
- 不录口播、不加BGM/字幕/滤镜，保留现场声音；交付原视频，不发压缩版。

## 先试拍两条

先拍04连续切档、06喷雾侧面，原片发来确认机位和水型可见程度，再照同样布置拍其余镜头。若希望一次拍完，仍先在手机上检查这两条。

## 推荐拍摄顺序

1. 试拍04、06并检查水型是否看清。
2. 擦干商品，拍01、02、03、09；方便再拍10。
3. 接水，固定机位和供水开度，拍04、05、06、07、08。
4. 回看每组至少一条，确认清楚再收设备。不必重复拍已合格镜头。

## 每条回看只检查这六项

- 商品、按钮和主要动作没有被手挡住或裁掉。
- 对焦稳定，没有突然变亮、变暗或明显闪烁。
- 银色高光仍有边缘与细节，不是一片白。
- 水型肉眼能分辨，喷雾没有被背景吃掉。
- 开头结尾均留了稳定停顿，没有动作做到一半就停。
- 无品牌包装、无关商品、个人信息或镜面杂乱反射入镜。

## 发素材与后期安排

保留手机原片。可以分组发送并说明“01外观、03除垢、05普通、06喷雾、07混合”，无需自己改每个文件名。每组挑清楚的一两条即可，失败片不用特意传。

拟成片顺序：外观开场 → 侧面/面板 → 下方按键与三档展示 → 红钮按压 → 手掌接水 → 商品收尾。根据素材可调整，不强凑时长。

后期由本会话负责选镜头、节奏、基础调色、大字字幕、BGM/水声混音和MP4导出；AI配音按实际工具与可用声音制作，付费资源先确认。建议文案只围绕“3档出水 / 下方按键切换 / 按压辅助除垢”。音乐授权另核，不直接截用参考BGM。缺少动作素材不能靠AI发明真实水流、红针动作或内部结构。
