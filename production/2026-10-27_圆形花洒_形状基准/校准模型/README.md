## 实际修改

1. 复用旧外壳连续拓扑，依据本次339/340/342/343及视频概览重校比例和侧面：模型总长约275mm、头径130mm；降低旧握柄弯曲和下柄厚度，头面倾角略调，头中心上移。数值是模型参数，不是实测。
2. 外露圆柱厚边建模22mm；浅拱背壳另保留，旧背壳超出圆柱的深度压浅。349/355提供约2cm量级支持，无法据照片确定精密厚度。
3. 黑面板沿圆头连贯延至切档键下方；修掉旧圆片下沿的曲率亮线，尾端为短圆弧。中央红钮、下方银色切档键独立分件。
4. 按348可辨布局制作15行交错白孔，逐行数`4,7,10,11,12,13,10,10,10,13,12,11,10,7,4`，共144个。每个是有环口、内壁与暗色底的三维简化孔口，非贴图；坐标在`white-hole-layout.json`，孔口尺寸仍为外观估值。
5. 外围按实拍保留3道细孔圈，模型采用每圈100个简化口缘。**300不是实物孔数结论**；未完成逐个数孔与角度标定，孔口不贯穿面板、不连接内部水路。
6. 接口为白色分件，简化可见螺纹；修正第一次导图发现的接口深度偏心。螺距、牙型、接口标准均UNKNOWN。
