## 编辑与复现

每张有同名`.blend`，保存其机位、姿态及全部浴室布景。`render_bathroom.py`用Blender 5.2.2原生生成三份场景并渲染；`verify_bathroom.py`独立重开核验。无需外部贴图或新增依赖。

在独立新目录放入源包后依次运行`Blender -b --python render_bathroom.py`、`Blender -b --python fix_niche.py`，随后运行`Blender -b --python verify_bathroom.py`。脚本会写入所在目录对应产物，复现时另建目录保护本版。

`单图任务卡.md`、`source-manifest.json`及`sources/`保存本轮来源和双重审阅要求。目标模型Astra/medium，实际运行模型字段UNKNOWN。唯一制作Owner为本会话。
