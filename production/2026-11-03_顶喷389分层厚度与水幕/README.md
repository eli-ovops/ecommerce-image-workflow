# 389分层代表候选：结构改善，水流真实感仍待审

本轮仅389。未替换现行13张，也未将候选放入成品包；其他12张原字节核对见verification.json。

## 实际方法

- 实际重开现有Blender模型，壳体局部包围尺寸0.300000012×0.200000003×0.0199999996m，缩放1。尺寸约300×200×20mm，不含拉钮和接头。没有增厚几何。
- 单一372实拍校正面板作贴图；无第二层生成孔纹。中央照片钮的原有遮挡区由既有3D红钮覆盖，不是整件原像素硬锁。真实孔、盲圆点和叶纹来自照片，但斜角投影与插值影响显示。
- 安装和静态展示分别渲染。首次静态视角裁切不合格，保留；调整相机后重新渲染，最后采用static-dry-v3.blend。商品形状不随相机调整。
- 单独生成冷蓝浴室和远端水幕，只输入原始商户389参考；没有使用旧AI广告或失败候选。背景不含商品，商品全部由原生渲染层提供。
- 从既有实拍分类坐标投影94个候选孔口，2处不确定点沿用排除，绘制近孔连接段，远端与独立生成水幕衔接。连接段不是流体仿真；远端水幕没有逐孔一一匹配。不宣称厂家孔数、逐孔硬锁或实测出水。红钮遮挡处连接段被遮掉。
- 粗斜中文、蓝色底条、商品和阴影独立分层。未新增尺寸文案。

## 实际审阅

已打开最终整图及孔口/侧壁、静态商品的200%细节。较两次全图AI失败候选，长方形比例和银侧壁可控，面板不再生成破碎叶纹或额外密排孔。下段水幕更自然，但孔口附近仍有细线感，与远端衔接可见；红钮及银壳反光仍有CG感，静态展示与环境的融合偏弱。因此仅交代表候选，不称389修复完成或客户验收。
