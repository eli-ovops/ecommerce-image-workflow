# 长方形顶喷：两张磨砂材质精修审阅稿

2026-10-30。按用户“质感是有点磨砂的”“继续做”精修同一组全貌与静态近景。原件与旧候选保留，未发布。

## 改动

黑色面板采用物体坐标的细噪声、粗糙度变化及法线凹凸，依据本轮实际查看的372、376、382实拍；不使用顶点位移。红钮调整为更饱和的橙红色及柔和反射。银壳保留原镜面材质，依据373/374实拍；改中性侧光并减弱暖边光。背景继续暖金方向。

颗粒大小、粗糙度、颜色均为视觉估计，不是材质测量结果。参数见material-changes.json。

运行：Blender -b --python refine_materials.py；核验：Blender -b --python verify_scene.py。脚本会写入所在目录的对应产物。

300×200×20mm候选模型的五个商品对象保持原顶点/拓扑、世界矩阵及修改器；孔纹、花瓣纹、红钮比例未重建。材质只改黑面与红钮，银壳、接头、防尘盖材质不变。此一致性不代表实物精密几何通过；96孔/132盲圆点沿用原候选，本轮未再逐孔验收。接头仍是原有带防尘盖状态，未展示去盖滤网。
