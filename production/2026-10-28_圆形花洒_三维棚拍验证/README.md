# 圆形花洒：完整三维棚拍验证

本轮只验证一张无字、无人、无水的 Blender 棚拍图。商品、桌面、灯光、反射及接触阴影全部在同一场景成像，没有 AI 商品像素或抠图商品层。仍为用户审阅稿，不称照片级或精密重建。

## 编辑与复现

- `圆形花洒_三维棚拍.blend`：可编辑商品、材质、相机、三盏矩形灯和桌面。
- `studio.py` / `recess.py` / `finish-rings.py`：从原 v1 读取并创建新场景；保留整体外形、144 白孔位置。增加小倒角、面板实际开口、白环下沉及暗底，外围数量仍是原模型的近似值。
- `review.py`：重新打开新 blend，导出同机位灰模及近正面灰模。
- `compose-review.js`：仅确定性拼排339实拍与灰模，原照整件统一旋转/缩放，不局部拉伸。
- `verification.json`：实际输入路径与 SHA、路由字段、修改、限制与交付哈希。

使用已安装 `/Applications/Blender.app/Contents/MacOS/Blender -b --python studio.py` 可重建基础场景，再运行 `finish-rings.py` 重建64段随面板曲线的白环，最后运行 `review.py` 出审查图。源模型路径在脚本内；保存的 blend 自身不依赖外部贴图。重建会写本目录候选，原模型不改。

## 判断边界

实开339、340、342、345、348、349。同机位灰模用于区分光照与轮廓；实拍正面对照只作近似角度观察，相机未标定，不能计算毫米误差或宣称轮廓硬锁。130mm头径等为继承模型值，不是本次测量。

保留白色螺纹；螺纹规格未知、牙形简化。外围细孔计数近似，红钮及白环截面仍是照片估建；无内部水路。银色、黑面微纹理及灯光是光学近似，不推断材料等级。当前只展示该机位，不用单张成图证明所有角度正确。

中间候选PNG、日志、脚本、灰模和对照均为恢复及审查证据保留；不作为多张成品交付，不删除原件或旧版。

曝光校正：最终固定几何、材质、灯位后，`exposure.py` 将曝光从 -1.7 调到 -0.8 EV。重建顺序为 studio.py → finish-rings.py → exposure.py。选定 PNG 仅作为渲染源，`export.js` 一次输出1600×1600 JPG，拒绝覆盖。历史文件名中的 approved 仅为当时内部候选命名，不代表用户接受。

最终输出：`圆形花洒_完整三维棚拍验证.jpg`（1600×1600，一次导出），已实际打开全图与400px缩略。银键目前反射深色区，外围细孔在缩略图中较弱；不据此宣称真实感验收通过。最终 blend 已再次重开，无外部贴图依赖，仅3盏棚灯。

源包包括 sources/source-v1.blend、孔位JSON、参数和339原照，可独立重建；Blender需5.2兼容版本。拼排/导出需现有Node+Sharp（本机路径见JS，可替换为安装位置），不捆绑软件运行时。对照与同机位灰模来自同一几何，最后仅曝光改变。原件和旧七图未写入改动。
