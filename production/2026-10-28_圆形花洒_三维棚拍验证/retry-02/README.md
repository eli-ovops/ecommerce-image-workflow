## 失败原因

主候选下方外围孔漏出银色。射线核查显示肩部旧底壳位于暗背衬前方（`inspect.log`）。唯一修正把暗背衬移到壳体前0.08模型毫米，结果背衬又遮住下方数个白环，并形成灰斑。单移背衬无法同时保证孔底遮光与白环不穿插。需要在另一明确授权任务中统一重建面板、底壳及孔口截面；继续移动背衬或调灯不解决这个几何矛盾。本轮不再修。
