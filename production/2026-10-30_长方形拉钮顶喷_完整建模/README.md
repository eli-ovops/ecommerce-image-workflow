# 长方形拉钮顶喷：可见外观模型 v3，待用户审阅

唯一制作目录为本目录；2026-10-30新品独立建模。旧圆形产品未修改、未恢复、未删除。

## 交付入口

- `长方形拉钮顶喷_v3.blend`：可编辑外观网格、三色材质、10个审阅相机及照明。默认银色，三色材质已设置持久保留。
- `build_model.py`：完整可复现建模与渲染脚本；依赖现有 Blender 5.2.2 的 bpy/bmesh/mathutils 与 Python 标准库，无外部贴图、插件或下载依赖。
- `verify_model.py`：重新打开 blend 后的几何检查。
- `hole-map.csv`：229个可见纹样中心的逐项分类与来源：96个可见通孔、132个实心圆点、1个拉钮遮挡位置。不是厂家确认的总孔数。
- `hole-map-source-overlay.jpg`：372原照校正预览上的编号；绿色通孔、黄色非孔圆点、紫色遮挡。`circle-contact.jpg`为逐点实拍裁切审阅证据。
- `01`—`10` 开头、结尾 `_v3.jpg` 的10张当前审阅图：正/背/长侧/短侧/斜视灰模、银色正斜、三色背斜、面板细节。
- `geometry-check.json`、`reopen-verification.json`：建模及重开检查结果，不能替代实物与用户验收。

运行（将工作目录切到本目录）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python build_model.py
/Applications/Blender.app/Contents/MacOS/Blender -b 长方形拉钮顶喷_v3.blend --python verify_model.py
```

重跑将写本目录同名生成物；如需保留当前修订，先复制脚本到一个新版本子目录运行。当前保存的 blend 与渲染不依赖实拍文件，原照仅作外观依据，没有商品照片贴面。

## 未确认与最小补拍

1. 接头：去掉白色保护盖后，拍一张正对开口、一张无遮挡侧面，旁放毫米尺。用于核螺纹、内部开口及接头真实长度；当前没有猜建标准螺纹。
2. 拉钮与短针：同一侧面角度拍复位/完全拉出两张，毫米尺与运动轴尽量同平面，再补一张拉出状态下完整正面，手避开面板。用于核行程、针伸出长度、遮挡区与全部针的位置。
3. 若需要制造精度，仍需孔径/圆角/凹座深度实测或工程图；现模型仅外观用途，不因补两张照片就升级为精密模型。

短红针伸出已由382确认存在；本版不设未经测量的针长、不建立隐藏联动机构，也不输出伪精确的“拉出”状态。中央被拉钮遮挡处不按重复花纹补成出水孔。
